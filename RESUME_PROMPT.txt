POWERSHELL GOTCHAS (learned this session):
- `curl` is aliased to Invoke-WebRequest. Use `curl.exe` for actual curl, OR use `Invoke-RestMethod` for JSON (handles ConvertTo-Json on the body cleanly: `Invoke-RestMethod -Uri ... -Method POST -ContentType 'application/json' -Body (@{query='...'} | ConvertTo-Json)`).
- `&&` is not a valid statement separator; use `;` instead.
- Heredoc (`cat <<'EOF' ... EOF`) doesn't work; for long commit messages either keep them short or write to .git/COMMIT_MSG_TMP first then `git commit -F`.
